LANGUAGE INSTRUCTIONS

    Three annotators wrote their own description of the same ten seconds. Two of them call the block orange. Language labels are noisy, and models trained on them have to cope.

    The reward is 0 on every frame except the last, where it becomes 1. That single bit is all the "success" signal a learning algorithm gets from this episode.
